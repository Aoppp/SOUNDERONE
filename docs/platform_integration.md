# 平台接入清单

## 已具备

统一入口支持 `taobao`、`douyin`、`jd`、`pinduoduo`、`xiaohongshu`、`wechat_store`、`kuaishou`、`mogujie`、`dewu` 和 `simulator`。当前 GenericAdapter 是开发契约，不代表已符合任何平台的生产协议。

每个真实适配器必须完成：

1. 官方 webhook 验签、时间戳和重放保护。
2. 平台事件转换为统一消息，保留原始事件 ID 做幂等。
3. 把统一回复转换为平台消息格式并调用官方发送接口。
4. 实现转人工/建工单语义，传递完整上下文。
5. 处理令牌刷新、限流、重试、死信与监控。
6. 用平台沙箱或测试店完成认证和回归。

## 需要业务方提供

- 各店铺所属主体、开放平台应用 ID、已申请权限和沙箱账号。
- 当前客服系统名称，以及能否提供 API/Webhook。
- 每个平台的一份脱敏入站事件、一份出站回复和一份转人工事件样例。
- 旺店通企业版 API 文档、应用凭证、可查询字段和网络白名单要求。
- 人工客服工作时间、队列/技能组、超时升级和节假日安排。

## 推荐优先级

先完成抖音生产适配（流量最高），同时确认现有抖音 AI 的供应商、转人工协议和错误案例；第二批完成淘宝/天猫、京东、拼多多；第三批依据实际咨询量安排其余五个平台。
